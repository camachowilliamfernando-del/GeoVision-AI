Guía de Detección

Cómo usar: Coloca la figura geométrica (o el objeto con esa forma) dentro del círculo verde central. El sistema solo analizará esa región circular.

Objetos → Figuras:

  • Tapa de botella, moneda, plato → Círculo
  • Cara de caja, dado, ventana → Cuadrado
  • Celular, libro, puerta → Rectángulo
  • Señal de tráfico, sándwich → Triángulo
  • Pelota, naranja → Esfera
  • Dado, caja de regalo → Cubo
  • Lata, vaso → Cilindro
  • Cono de helado, embudo → Cono

Consejo: Usa fondo contrastante. Si no detecta bien, entrena con KNN manual.
